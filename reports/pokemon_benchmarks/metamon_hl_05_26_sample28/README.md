# Held-out gen1ou teams: Metamon hl_05_26 sample (28)

28 teams sampled (seed 20261026) from Metamon team set `hl_05_26` (high ladder, May 2026: 1400+ ladder and smogtours
revealed teams), gen1ou, downloaded 2026-10-26 with metamon.env.wrappers.download_teams. Kept only teams with six
