Magnet KL Reference

One mechanism covers EMAgnet, BC anchors, uniform-ish anchors and plain entropy: pull the policy toward a reference policy with a KL penalty. This page lists what each setting does and how to reproduce each paper's method.

The idea in one line

Add a penalty to the PPO loss for drifting away from a reference policy. The paper calls the reference a magnet; other papers say anchor or prior. Everything else is three choices: which reference, which KL direction, and how strong the penalty is over training.

loss = PPO loss + magnet_coef · KL( magnet ‖ policy )      default (forward)
loss = PPO loss + magnet_coef · KL( policy ‖ magnet )      magnet_reverse = 1

after each full pass over the rollout:
  magnet ← (1 − magnet_tau) · magnet + magnet_tau · policy

Every checkpoint also saves the magnet as <checkpoint>.magnet, a normal weight file. The training log reports loss/magnet_kl. Discrete actions only. The magnet reuses the learner's stored recurrent start states, so any replay_ratio works.

Ataraxos annealed with a power law; ours anneals with a cosine. Same shape idea: strong early, weak late. The Ataraxos reference is "pick a movable piece, then a legal move, uniformly", not a random network. random is the closest zero-effort stand-in.

Which KL direction

Forward: KL(magnet ‖ policy) default

Penalizes the policy for dropping actions the magnet still plays. It keeps mixing alive and prevents collapse onto one strategy. This is what EMAgnet and SPICE use, and it suits games where you want to stay unexploitable.

Reverse: KL(policy ‖ magnet)

Penalizes the policy for doing things the magnet would not. It keeps behavior inside what the reference considers reasonable: human-like, or a safe set. With a uniform reference, it is the entropy bonus up to a constant.

Strength over training

  • Moving reference (magnet_tau > 0): constant strength is fine. The target moves with the policy and stops pulling toward bad actions once the policy drops them. This is why EMAgnet beats annealed entropy in games with dominated strategies.
  • Fixed reference (magnet_tau = 0): usually anneal. Otherwise the anchor holds the policy back late in training. Ataraxos found that annealing too fast gave quick gains but collapsed entropy.
  • Evaluate the magnet too. EMAgnet's magnet often beats the last iterate (0.007 vs 0.015 on 4-card Goofspiel). Ataraxos also found the EMA of weights at least as good, with less seed variance. The Goofspiel eval scores both and keeps the better one.
