# Gen 3 OU data (downloaded 2026-11-06)

- `gen3ou_sets.json`: Smogon analysis sets, 106 species (https://data.pkmn.cc/sets/gen3ou.json): moves, item, ability,
  nature, EVs, IVs per named set.
- `gen3ou_stats.json`: Smogon usage statistics for gen3ou, 141 species (https://data.pkmn.cc/stats/gen3ou.json):
  weighted usage, abilities, items, moves, spreads and teammates per species.

For the Gen 3 OU training run: team generation (species by usage and teammate pairs, sets from the analyses and the
usage spreads) and the combination/core curriculum adapted from the Gen 1 work.
