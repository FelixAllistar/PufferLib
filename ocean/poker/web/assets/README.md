# Casino felt

`casino-felt-v1.webp` is a generated wool-baize material, used by `casino.css`.
The built-in image_gen tool produced the original PNG on 2026-10-19. FFmpeg
encoded it as WebP at quality 80 without resizing or altering its composition.
The browser shades the material with CSS and keeps the playing cards, labels,
rail, controls and state feedback as responsive DOM/CSS elements.

The exact concept and material prompts are retained in
[`imagegen-prompts.json`](../../../../reports/poker/20261019/web_v7/imagegen-prompts.json).
The concept is an art-direction reference, not a screenshot of the shipped game.
