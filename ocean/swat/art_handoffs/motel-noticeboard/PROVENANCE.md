# Provenance

Created from scratch in this local workspace for the explicitly requested Briar Court reception art gap. Task supplied verified Slack references C0C5TN3AA8K / thread 1791078311.943659 / messages 1791588583.792269 and 1791589156.158709, describing a compact reception chair or worn wall noticeboard with clear routes. Parent catalog audit reported zero noticeboard matches and six existing chairs, so a noticeboard was selected.

Original parametric geometry, generated cork/wood/paper textures and fictional notice copy. No downloaded model, photograph, third-party texture or copied branded sign was used. Shared project tools informed packaging/audit structure only. Local bundled DejaVuSans.ttf and DejaVuSerif-Bold.ttf came from /usr/share/fonts/truetype/dejavu; actual distribution copyright/license is reproduced separately. Original asset art is dedicated CC0; font software remains under its own license. No pixel/block lettering.

No external upload, publication or engine modification performed. Mount locations are reference coordinates only, source remains unplaced. Requested exclusions are preserved: no floorplan alteration or floor/door-route occupancy.
