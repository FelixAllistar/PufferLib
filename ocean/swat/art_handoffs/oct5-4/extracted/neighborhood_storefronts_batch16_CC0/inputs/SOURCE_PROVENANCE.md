# Source provenance

Fifteen full GLBs are byte-identical copies of prior original CC0 batches. See ../reused_assets/reuse_catalog.json for exact IDs, hashes, dimensions, and source paths. Original manifests and license texts are preserved in prior_asset_provenance/.

materials_v1/ contains all six latest material families, eighteen runtime maps, editable source scripts, original CC0 scan inputs, licensing, manifests, and prior QA reports. QA render images and caches are omitted. Files copied from the source package are unmodified.

The older provisional imagegen plaster is neither copied nor covered by this CC0 claim. This package preserves the explicit distinction in materials_v1/LICENSE_CC0.txt. New procedural plaster candidates are separate original procedural works with their own dedication.

The folding card table is reused unchanged as a folding surface; no dedicated laundry folding table was found. Every reused object remains art-only with no collider or gameplay binding.

The additional frosted_dome_light fixture is copied from batch 05 and verified separately from the initial 14-asset packaging script. It retains its ceiling-pan origin: source Z=0 mounting plane, with geometry extending down to Z=-0.151 m.
