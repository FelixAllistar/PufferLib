# Distinct guest-room numbers

[Delivered package](https://drive.google.com/file/d/1mgGm7UmpCyIDFrSkRg9ZxCN9ytItyDWo/view).
All delivered SHA256SUMS verified before import. The delivered 101 is byte-identical
to the already accepted Room 101 v3 plaque, so no duplicate runtime 101 is retained.

102–104 use the same 132 triangles, four primitives, three materials, UVs and
0.32 × 0.17 × 0.0318 m bounds. Only the painted number images differ. The explicit
instance mapping owns placement; inherited 101 GLB extras are provenance:

| Number | Source instance | Live owner | Origin (metres, Y up) |
| --- | --- | --- | --- |
| 101 | 018 | 19 | (-6.4, 1.92, .11) |
| 102 | 042 | 43 | (-2.4, 1.92, .11) |
| 103 | 066 | 67 | (1.6, 1.92, .11) |
| 104 | 090 | 91 | (5.6, 1.92, .11) |

Replacement art follows original owner visibility/destruction and changes no
physics, navigation or network IDs. Each optional number has independent fallback
to the original plaque; location teardown releases every replacement and texture.
Native `room-number-101.png` through `104.png` provide matching close views.

Source blend, images, font and font license, bindings and QA metadata are retained
under `source/`. The duplicate baseline/context exports and delivered scripts are
omitted. Art is CC0; the bundled DejaVu font retains its own supplied license.
