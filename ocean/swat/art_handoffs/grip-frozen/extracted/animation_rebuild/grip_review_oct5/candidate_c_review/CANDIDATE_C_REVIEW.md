# Candidate C: qualified static comparison option, with a local crease caveat

**C is a useful but modest static support-grip alternative for A/B review. It is not a material-clean pass or an automatic replacement for frozen A.** The measured palm moves slightly inward/upward, the cup looks a little tighter in the exact same physical cameras, central-distal palm seating improves, and the index/middle remain separated. The independent gate finds no new nonlocal self-intersection or elbow-cap collision.

Two tradeoffs must remain visible in the disposition:

1. Maximum sampled rifle-in-glove overlap rises **0.538→0.825 mm**. No sampled point exceeds 1 mm, but this is not a zero-intersection result.
2. A pre-existing palmar index-base crease becomes more compressed: one native triangle drops **16.09→6.67%** of rest area. A targeted close render shows a slightly narrower, more pointed crease/shading transition. This is a real local material regression, even though the face remains positively oriented under the transport diagnostic and introduces no self-crossing.

Keep A available. C can be presented as an explicitly qualified, bounded static option if this subtle seating benefit is worth the disclosed crease/contact tradeoff. This review makes **no full-palm support, engine ADS/camera/eye-relief, transition, or animation-motion claim**. No candidate, input, or action was edited during review.

## Final boundary of the result

**Qualified for static A/B presentation with the crease and overlap caveats disclosed. Not a clean replacement certification.** C modestly improves the requested supported-hand appearance and central-distal seating while avoiding B's concrete collision failures. It does not fully solve broad proximal-palm stand-off, and the compressed index-base face prevents calling it material-clean. Retain A for comparison and leave final selection explicit.
