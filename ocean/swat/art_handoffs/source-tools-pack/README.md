# Shared CC0 tool source

`Tools_Pack_original.zip` is the unchanged original SirDraco65 "Set of 18 PBR
Tools" archive, retained once for source preservation and reuse across prop
handoffs. It is 68,956,665 bytes, SHA256
`0780e8fcfc11ffb4165727f00ad96aff9255e024c2aeaa73bb522d0e428b938c`.
It contains the original FBX, OBJ, 3DS and texture ZIPs, including supplied LODs.
This does not install the other tools or accept their runtime models.

The author listing and CC0 provenance are preserved under
`../motel-screwdriver/source/`. The screwdriver handoff's original README points
to a local `source/Tools_Pack_original.zip`; that identical archive lives here
instead to avoid repeated copies. Artist scripts are archival and were not run.
