# Motel bedside wall reading lamp

One original, unbranded CC0 wall-mounted reading-lamp housing with integral pushbutton. Warm ivory opaque metal shade, satin metal plate/fixed arm and dark polymer button. No bulb mesh, actual light, emission, collision or interaction is included.

- LOD0: 952 triangles. LOD1: 378 triangles.
- Approximately 110 × 198 × 196 mm (width × height × depth); 80 × 120 mm backplate.
- Editable Blender source, two GLBs, original 512 px PBR maps, independent UV1 AO, build and audit scripts.
- Eight named mesh parts and ANCHOR_bulb_light. Rear wall-contact-center pivot, metre units.

Preview images are neutral Blender renders of the shipped GLBs, not game captures. The headboard silhouette in the separate placement proposal is only a render helper and is not included in runtime art. Proposed mounting is beside the headboard, clear of the wall print; exact motel placement remains undecided.

Use ENGINE_IMPORT.md for ownership, rebuild and runtime limits; MANIFEST.json and QA files for measured results. This package does not edit any pinned assets or current catalog.
