# Provenance

Original procedural game asset made for this delivery. No downloaded meshes, photographic textures, brand marks, scans or prior prop meshes were used. Geometry and atlas layout are authored in source/build_asset.py and source/make_atlas.py. Small deterministic noise/scratch marks are generated using a fixed random seed.

Original geometry, textures, scripts and documentation: CC0-1.0, see LICENSE.txt. The procedural build/export/audit scaffolding was adapted from the earlier original CC0 service-trolley source, but no trolley geometry or texture pixels are reused.

Text is rasterized with the installed DejaVu Sans Bold font. Font output is permitted by its license; the font file is not bundled or relicensed. See source/FONT_LICENSE.txt for dependency licensing. Blender 4.3.2 and Python/Pillow are build tools and are not included or relicensed.
