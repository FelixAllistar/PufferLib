# Roadside waiting shelter · BC_SHELTER01 r01

Original static environment-art candidate for a connected street edge. A modest open-front shelter with a fixed timber bench, opaque folded steel rear screen, a sloping corrugated roof, open gutter and hollow downpipe. It has no transit logo, route, timetable, assigned map location or implied placement approval. No previously delivered asset was modified.

## Files and scale

- Runtime: `runtime/BC_SHELTER01_static.glb`
- Editable: `source/BC_SHELTER01_editable.blend`, with all five source images packed
- Dimensions, width × depth × height: **3.220 × 1.689 × 2.379 m**
- **7,868 triangles, 3 opaque single-sided PBR materials, 3 mesh nodes / 3 material primitives, 5 embedded PNG images**
- Eight descriptive anchor empties plus one root; no rig, animation, skin, lights or cameras
- Source has 160 named editable solids. These are intentionally consolidated by material for runtime export.
- Metres; identity root at ground level between the four footplate centers. Every runtime mesh uses that common pivot.
- Blender: X width, Y depth, Z up, front −Y. Standard glTF: X width, Y up, front +Z. **Do not convert the axes a second time after a normal glTF import.**

The bench is 2.40 m wide, with a nominal seat top at 0.470 m and 0.443 m slatted seat depth. Three cantilever supports attach it to the rear frame. The back leans approximately 10 degrees. These are visual/ergonomic design choices for fictional game art, not construction, load, safety or accessibility specifications.

## Rebuild

Requires Blender 4.3.2 and Python 3 with NumPy/Pillow. No network, add-ons or external model files are required.

1. `python source/make_textures.py`
2. `blender -b --python source/build_shelter.py`
3. `blender -b --python source/render_export.py`

`SHELTER_OUT=/absolute/fresh/output` redirects new texture/build outputs. The geometry recipe reads its input maps beside itself; copy the source recipe and maps together for an independent relocated build. `steel.png` is an inherited immutable input, not regenerated by the texture script. Original generated maps are deterministic.

For a packed-only export without the maps folder:

`blender -b --python source/export_packed.py -- /path/BC_SHELTER01_editable.blend /path/output.glb`

The packed-source export promises equivalent geometry, UVs and PBR data, not byte identity or object ordering. `render_export.py` always imports the runtime GLB afresh; its neutral review floor, lights and cameras are never in the asset.

## Scope and handoff

This is a **static art candidate**. The engine owns scene placement, collision, occupancy/interaction, cover classification, navigation, destruction/support behavior, water effects, native import and platform performance. None is supplied or accepted here. Anchor names are descriptive only. No native engine test or target-platform performance test has been run. Material-primitive counts are an offline inventory, not a certified draw-call or frame-time claim.

The source is an assembly of overlapping fabricated parts, not a globally boolean-unioned solid. Individual source solids are checked separately; arbitrary spatial welding of the consolidated runtime can create contact edges that are not globally manifold. Small overlaps at bolts, rails, folded sheet and plate contacts are intentional. There are no transparent planes standing in for the rear screen or roof.

The checks and actual-export preview bindings are in `qa/`. Design contacts, coordinate basis and full node/material inventory are in `docs/` and `MANIFEST.json`. Independent audit results, once included, are attributed separately from builder checks.

Only material UV0 is supplied; the steel intentionally repeats. No lightmap UV set or LODs are supplied. Independent checks cover decoded geometry, PBR, contacts, reproducibility and visual bindings; they are not a full Khronos validator run or exhaustive self-intersection certification.
