3. Authoring workflow and provenance evidence

The kit was generated on Felix's behalf through original deterministic Python
and Blender authoring. The inspected source uses seed 230808. Soil surfaces are
constructed from numeric grids and analytic heights. Rocks are deformed primitive
geometry; woody shrubs, opaque leaf meshes and scatter are constructed directly
in code. There is no imported third-party model in the authoring path.

make_textures.py creates five material sets (gravel_soil, bank_soil, stone, bark,
leaf), each with base color, tangent normal and roughness maps at 512 x 512.
Their pixels come from seeded numeric noise and periodic derivatives. All 15
maps were regenerated in an isolated temporary directory and matched the
archived PNGs byte for byte. No downloaded maps, scans, paid assets, external
texture reuse, or image-generator output are inputs to this workflow.

The inspected .blend contains no linked libraries, font datablocks, or text
objects. Its 15 file-backed images are packed and correspond to the original
map set; the additional empty Render Result viewer is not an asset input.
All five runtime GLBs were checked for embedded images/buffers and contain no
external image or buffer URI dependencies. Every file member of both archives
was compared to the inspected local kit and matched byte for byte.

The existing kit README and determinism report also record this procedural
workflow and runtime reproducibility. This addendum's verification checks are
recorded in VERIFICATION.json and blend_inspection.json. The provenance statement
is based on the supplied authoring source, archive/file inspection and the map
reproduction test; it is not a warranty of third-party rights clearance.
