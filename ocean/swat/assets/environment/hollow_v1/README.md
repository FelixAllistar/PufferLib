# hollow_v1: The Hollow (`--mission hollow`)

These are the presentation assets for The Hollow. See `ocean/swat/HOLLOW.md`
and `reports/cloud/level-hollow/LOG.md`. Nothing here is read by the
simulation. Collision is the authoritative box map in `hollow_impl.h`.

## materials/ (CC0, Poly Haven, https://polyhaven.com/license)

Each file is an unmodified Poly Haven JPEG map (diffuse, OpenGL normal,
roughness), renamed. The renderer (`hollow_art.h`) puts them on the
authoritative boxes with metric UVs.

## GLB models (made here)

These are generated by this repository's own Blender scripts, which are
deterministic:

```sh
python3 tools/blender/hollow_textures.py TEX_DIR assets/environment/hollow_decals  # procedural textures + decal atlas
blender -b --factory-startup --python-exit-code 1 -P tools/blender/hollow_scene.py -- assets/environment/hollow_v1
blender -b --factory-startup --python-exit-code 1 -P tools/blender/hollow_props.py -- assets/environment/hollow_v1/props TEX_DIR
```

- **Textures:**
  - The CC0 Poly Haven maps listed above, plus Bark Brown 02, Gravel Floor 02,
    Dry Decay Leaves, Rusty Metal 02 and Rusty Painted Metal (all Poly Haven,
    CC0), downscaled to 512 px or 1K and embedded.
  - Procedural textures made here, under `textures/`:
    - Flyers and newspaper: silhouettes only, no real names, faces or cases.
    - Ticking, tarp, linoleum and the bus lettering.
    - Stylised stains.
- **Collision:** the authoritative box map. The prop placements come from
  `hollow_data.h`.
- **Loader limit:** at most 7 materials per GLB, which the scripts assert.
- **Total: 91610 triangles.**
