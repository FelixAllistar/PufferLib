# Briar Court surroundings (presentation only)

Generated by `ocean/swat/tools/blender/motel_surroundings.py` with Blender 4.2:

```sh
blender -b --factory-startup --python-exit-code 1 \
  -P ocean/swat/tools/blender/motel_surroundings.py -- [OUT_DIR]
```

The script has no external inputs (fixed seeds, procedural geometry and
textures) and reproduces these files byte for byte. `manifest.json` lists
triangle/vertex counts, the decal layout and SHA-256 hashes.

| File | Content |
| --- | --- |
| `backdrop.glb` | Far terrain ring outside the playable envelope (x -64..64, z -48..52) to +-900 m, two hill rings (300-430 m, 560-900 m), tree lines and scrub, neighbour silhouettes (gas station, diner, houses, warehouse, closed shop, water tower, billboards, farm), utility poles/wires beyond the envelope. One material: vertex colour x embedded tiling grain. |
| `near_props.glb` | Lot curbs, driveway curbs, the sidewalk along the highway, four cobra-head streetlights, six lot pole lights, near utility poles/wires with a transformer, a hydrant. |
| `road_extension.glb` | The highway continued from x=+-56 m outwards. Material 1 (asphalt) is drawn with the existing CC0 `motel_asphalt` maps; material 2 holds the painted lines. |
| `ground_decals.png` | 1280x2048 RGBA (straight alpha) world-XZ mask: rows 0-1599 lot+driveway (x -24..24, z -24..36), rows 1600-1823 road west half (x -56..0, z 36..44), rows 1824-2047 road east half (x 0..56). Bay paint, accessible bay, arrows, stop bar, fire-lane hatching, cracks, tar seals, alligator cracking, patches, oil stains, tyre polish, edge dust, low-frequency wear. |

None of these objects exist in the simulation: no collision, navigation,
cover, visibility or wire data. Thin poles and 7 cm curbs may visually
intersect a character's feet; that is expected for presentation-only art.
