# Briar Court surface decals (presentation only)

Generated by `ocean/swat/tools/blender/motel_decals.py` (numpy only; runs with
`python3` or Blender 4.2's Python; fixed seeds, byte-reproducible):

```sh
python3 ocean/swat/tools/blender/motel_decals.py [OUT_DIR]
```

| File | Content |
| --- | --- |
| `decals_color.png` | 2048x1536 RGBA8: sRGB albedo, straight coverage alpha. 256 px cells on an 8x6 grid; transparent texels carry the tile's mean colour (no dark mip fringes). |
| `decals_nr.png` | 1024x768 RGBA8 (half resolution, same UVs): RGB OpenGL tangent-space normal from a per-tile height field, A roughness. |
| `atlas.txt` | Generated manifest: atlas files, grid, and per tile its cell rectangle and default size in metres. |
| `placement.txt` | Hand-written placement: seeded scatter rules per surface kind and hand-placed hero decals. Grammar in `ocean/swat/surface_decals.h`. |

Tiles: `streak_a/b` (sill water streaks), `roof_runoff`, `rust_a/b`, `ac_drip`,
`frame_grime`, `handle_grime`, `grime_base`, `splash` (downspout splash-back),
`scuff`, `tyre`, `oil`, `burn`, `burn_b` (cigarette burns), `stain_a/b/c`,
`carpet_wear`, `grout_grime`, `mould`, `mould_big`, and three original graffiti
tags `tag_vexo`, `tag_rumb`, `tag_glyph`.

Nothing here exists in the simulation. See ENVIRONMENT_ART.md "Surface decals".
